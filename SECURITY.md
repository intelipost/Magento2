# Política de segurança / Security policy

## Reportar uma vulnerabilidade

Se você encontrou uma vulnerabilidade neste módulo, **não abra uma issue pública**.
Reporte de forma privada pelo GitHub:

1. Acesse a aba **Security** deste repositório.
2. Clique em **Report a vulnerability**.
3. Descreva o problema, a versão afetada e, se possível, os passos para reproduzir.

O link direto é https://github.com/intelipost/Magento2/security/advisories/new.

O relato fica visível apenas para os mantenedores. Respondemos pelo próprio advisory,
e a correção é publicada numa nova versão do módulo antes de qualquer divulgação.

## Reporting a vulnerability

If you found a vulnerability in this module, **please do not open a public issue**.
Report it privately through GitHub: go to the **Security** tab of this repository and
click **Report a vulnerability**, or use
https://github.com/intelipost/Magento2/security/advisories/new.

Only the maintainers can see the report. We reply through the advisory and publish
the fix in a new module release before any public disclosure.

## Versões suportadas / Supported versions

Correções de segurança são publicadas apenas na versão mais recente do módulo.
Security fixes are released for the latest version of the module only.
